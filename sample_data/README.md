# Sample Data

This folder contains two examples of real output produced by the market data analysis system.

## Recruiter-Friendly Sample

[`spread_events_recruiter_sample.csv`](spread_events_recruiter_sample.csv)

A simplified version of the collected data with the most important fields:

- Detection time
- Market symbol
- Buy exchange
- Sell exchange
- Initial spread
- Maximum spread
- Event duration
- Buy and sell prices
- Average spread

This version is designed to make the system output easy to understand at a glance.

---

## Full Technical Sample

[`spread_events_full_sample.csv`](spread_events_full_sample.csv)

A technical sample containing all fields recorded by the system.

It includes:

- Event timestamps
- Signal and confirmation timestamps
- Exchange information
- Spread statistics
- Price differences
- Bid and ask prices
- Available market sizes
- Event duration
- Historical spread information

Both samples contain 100 real recorded events from the same dataset.
